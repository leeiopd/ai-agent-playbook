# 설계 규율: 깊은 모듈과 seam

`AGENTS.md` 11번의 상세 원칙. 새 코드를 설계·구조화할 때 적용한다.

- **깊은 모듈을 지향한다.** 작은 인터페이스 뒤에 많은 동작을 둔다. 인터페이스가 구현만큼 복잡하면(얕은 모듈) 다시 설계한다.
- **인터페이스 = 테스트 표면.** 호출부와 테스트는 같은 seam을 통과한다. seam을 *지나쳐* 내부를 테스트해야 한다면 모듈 형태가 잘못된 신호다.
- **테스트 가능하게 짠다.** 의존성은 내부 생성 대신 주입받고, 부수효과 대신 값을 반환하며, 표면(메서드·파라미터)은 작게 유지한다.
- **seam 배치는 독립된 결정이다.** 기존 seam 우선, 가능한 한 높은 지점, 가장 적게(이상적으로 1개). adapter가 1개뿐이면 가상 seam이고, 둘 이상 실제로 달라질 때만 진짜 seam으로 도입한다.
- **테스트는 외부 동작만 검증한다.** 구현 디테일이 아니라 관찰 가능한 동작을 확인한다. 리팩터링으로 깨지는 테스트는 구현에 결합된 것이니 대상 표면을 재검토한다.
